### 📥 Установка

**Установка репозитория:**

.addrepo https://github.com/xmogdemaybe/modulesheroku/raw/main


**Установка конкретного модуля:**

.dlmod <название_модуля>


**Прямая установка по ссылке (RAW):**

.dlmod https://raw.githubusercontent.com/xmogdemaybe/modulesheroku/main/<название_модуля>.py
