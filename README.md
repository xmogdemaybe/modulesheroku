# modulesheroku

Личные модули для Hikka / Heroku Userbot.  
Писалось исключительно для себя, всё через иишку, реализация полная хуйня. Если что-то подошло тебе — пользуйся. Если нет — твои проблемы.

---

### 📥 Установка

**Установка репозитория:**

.addrepo https://github.com/xmogdemaybe/modulesheroku


**Установка конкретного модуля:**

.dlmod <название_модуля>


**Прямая установка по ссылке (RAW):**

.dlmod https://raw.githubusercontent.com/xmogdemaybe/modulesheroku/main/<название_модуля>.py

### 🐛 Нашёл баг?

Идёшь нахуй.

Репозиторий поддерживается только тогда, когда у меня есть на это желание и время. Если что-то крашнулось, отвалилось или перестало отправляться:
* Открываешь `.py` файл ручками и чинишь сам.
* Оформляешь нормальный Pull Request (если фикс адекватный — возможно, приму).
* Либо молча удаляешь модуль через `.unloadmod`.

Нытьё в Issues без готового решения будет закрываться без ответа.
